# TLS fingerprints: итоговый кандидат X 1.0.2, 2026-10-08

По новой просьбе владельца перенесён согласованный TLS/REALITY набор из
последнего релиза FiyeroT/podkop-engine v1.14.2-r12 (GitHub API проверен).
Оригинальные 0001, 0002, 0010, 0085 сохранены в patches/tls-fingerprints с
авторством FiyeroT, GPL-3.0-or-later и SHA-256 manifest. Адаптер применяется
после прежнего hardening/uTLS и до XHTTP; все прежние изменения сохранены.

Firefox теперь 148, Safari 26.3. REALITY сохраняет hybrid X25519MLKEM768 share
и объявляет client version 26.3.27. Random/randomized обновлены согласно донору;
для старых несовместимых fingerprints добавлены предупреждения/ошибки.
HTTP/3 и QUIC-транспорты не добавлены.

Итоговый executable 1.14.2-x-1.0.2, APK 1.0.2-r1, IPK 1.0.2-1.
Go 1.26.8, UPX 5.2.1. Unit/race и проверки графов, сборки и пакетов прошли.
Оригинальные source/артефакты прежнего XHTTP-кандидата сохранены в локальном
work/source-xhttp-before-fingerprints и work/dist-xhttp-before-fingerprints.
Не создавались новые бэкапы VM/роутера и не выполнялся пакетный откат.

По просьбе пользователя интеграционная проверка упрощена: один проход текущей
подписки на существующей OpenWrt 25 VM, затем один на GL-MT6000 192.168.90.1.
Штатная загрузка INCY/HWID и parser: 61 сервер плюс группа URLTest.
На обеих машинах 61/61 URLTest прошли без ошибок: 58 TCP REALITY, один gRPC
REALITY и два XHTTP TLS. Это проверка текущих серверов, не новая полная матрица
Xray 25/26.9, длительная нагрузка или замер RAM. Тестовые процессы запускались
при остановленном Forkop. На VM пакеты не менялись, Forkop снова работает.

На роутере по просьбе оставить ядро выполнено локальное offline обновление
sing-box-x 1.0.1-r1 -> 1.0.2-r1, --no-network --allow-untrusted --no-scripts.
APK кандидата не подписан и не опубликован; установка была узким исключением
для пользовательского роутера по новой инструкции. Зеркало не менялось.
Также оставлены три проверенных backend файла capability XHTTP:
singbox/runtime.uc, service/ui.uc, singbox/generator.uc. Frontend bundle не менялся.
