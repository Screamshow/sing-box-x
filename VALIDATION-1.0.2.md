# Sing-Box X 1.0.2: проверка кандидата, 2026-10-08

Кандидат собран на прежнем upstream 1.14.2 с Go 1.26.8 и UPX 5.2.1.
Версия исполняемого файла: `1.14.2-x-1.0.2`; пакеты: `1.0.2-r1` (APK),
`1.0.2-1` (IPK). Сборки подготовлены локально, не опубликованы; APK не подписаны.

## Изменения

Перенесены восемь патчей из podkop-engine `v1.14.2-r12`: ограничения сборки
QUIC ClientHello, разблокировка записи gRPC-lite/HTTP2 при ошибке запроса,
исправление сброса DoH-соединения, валидация протокольных входных данных,
закрытие соединений вне блокировок, ограничение пакетов и обработка panic
сниффера, экономия форматирования логов и ограничение хранения/вывода стеков.
Дополнительно адаптировано освобождение объектов uTLS после handshake.
Точные файлы, SHA-256, авторство и адаптации описаны в `patches/README.md`
и `patches/manifest.json`.

Отпечатки браузеров, версия клиента REALITY, зависимости и набор транспортов
сохранены. XHTTP и дополнительные QUIC-транспорты не добавлены.
Подготовка исходников проверяет хеши патчей и фиксирует эффективный набор
изменений и тестов в архиве исходников.

При локальной упаковке исправлена staging-директория APK: используется
файловая система Linux, сохраняющая права, вместо Windows DrvFS.
Проверены каталоги 0755, бинарник/init 0755, конфигурация/метаданные 0644,
владелец root. Проверены структура IPK, архитектуры ELF, длины и SHA-256
всех семи артефактов манифеста.

## Автоматические проверки

Unit- и race-тесты прошли для route, Clash API, trafficcontrol, sniff, JA3,
interrupt, TLS, log, DNS transport, gRPC-lite, HTTP, WebSocket и HTTP upgrade.
Новые регрессии проверяют настоящий Firefox TLS handshake с обменом данными
и повторным вызовом handshake, регистрацию при заблокированном Close,
таймаут DoH при живом соединении и восстановление зависшего соединения,
ограничение вывода и хранения panic stack. Проверки исключения native API
и наличия gRPC-lite в графе зависимостей прошли.
UPX integrity прошёл на обеих архитектурах.

## Реальная подписка и списки

Проверка выполнена на OpenWrt 25.12.5 x86/64 в существующей VMware VM.
Подписка получена штатным механизмом Forkop с INCY и HWID. Ссылка и
учётные данные не включены в исходники, отчёт или тестовые fixtures.

В подписке 61 узел. Штатный фильтр белого флага оставляет 58 TCP REALITY
и исключает один gRPC и два XHTTP. Проверены все 58 узлов и отдельно
исключённый gRPC: всего 59. Для каждого текущий X 1.0.1 и кандидат 1.0.2
работали одновременно с одинаковыми DNS, стратегией разрешения имён
и сетевой меткой Forkop; проверялся HTTPS-ответ 204 через соответствующий
прокси. Кандидат прошёл 59/59; исходный X прошёл 58/59 с первого раза,
единственный отказ исчез при отдельной попарной перепроверке. Отказов,
возникающих только на кандидате, не обнаружено. Это проверка доступности
на момент теста, а не измерение длительной стабильности или скорости.
Первые диагностические прогоны с отличающимся DNS не учитываются.

Регрессии SRS прошли на скачанном списке и фикстуре с 10 000 доменов:
вложенные правила, повреждённые/обрезанные/неподдерживаемые данные,
обновление кеша, сохранение последнего исправного списка и перенос
кеша из RAM во flash. В конфигурации с настоящим узлом отдельно проверены
JSON и SRS: HTTPS-загрузка успешна, Clash API подтвердил совпадение именно
с тестовым списком. Сохранены DNS и остальные списки сгенерированной
конфигурации Forkop.

Полный запуск и перезапуск Forkop с кандидатом и реальной подпиской прошли:
сгенерированы 58 VLESS-узлов и два rule-set; DNS и Clash API отвечают.
На OpenWrt 24.10.8 x86/64 также прошли запуск, перезапуск, DNS, Clash API
и регрессии SRS. ARM64 собран и проверен при упаковке, на устройстве не запускался.

## Размер и восстановление

Сравнение с X 1.0.1 при прежнем наборе build tags:

| Архитектура | UPX-бинарник 1.0.1 | UPX-бинарник 1.0.2 | Прирост |
| --- | ---: | ---: | ---: |
| x86_64 | 9 863 528 Б | 9 868 792 Б | 5 264 Б (0,053%) |
| ARM64 | 8 537 372 Б | 8 541 740 Б | 4 368 Б (0,051%) |

Размер извлечённого APK payload кандидата: 9 871 066 Б на x86_64,
8 544 026 Б на ARM64. Распакованный бинарник в RAM не считается расходом flash.

Кандидат запускался временной bind-подменой бинарника, без установки
локальных пакетов. До изменений сохранены пакеты, состояние сервисов
и конфигурации. Обе VM восстановлены на X 1.0.1: списки установленных
пакетов и SHA-256 бинарника, UCI Forkop/sing-box/DHCP и исходного runtime
config совпадают с состоянием до теста; DNS и Clash API работают.
Публикация и установка через зеркало в этот тест не входили.
